# 2026-11-02

## FlingTrainerX —— WPF 单机工具箱（仿 flingtrainer.com）

- 需求：按设计稿实现深色游戏库 App，数据取自 https://flingtrainer.com/（游戏名称 + 更新时间），卡片可点击，进入类似官网详情页的弹框。
- 数据：抓取 WordPress REST 接口 `https://flingtrainer.com/wp-json/wp/v2/posts?per_page=24&orderby=modified&order=desc`，
  解析正文首行 `NN Options · Game Version: … · Last Updated: …` + 「快捷键 – 名称」分组选项；内置 24 款 / 829 项到 `Assets/trainers.json`。
  竖版海报走 Steam CDN `steam/apps/{appid}/library_600x900.jpg`（15/24 命中），其余用官网截图 + 毛玻璃兜底。
- 结构：Models / Services(TrainerWeb 解析、TrainerDataService 缓存) / Converters / Themes/Theme.xaml / Views/TrainerDetailView（弹框）/ MainWindow。
- 技术要点：
  - 自绘标题栏用 `WindowChrome`（CaptionHeight=0），顶栏 MouseLeftButtonDown 手动 DragMove + 双击最大化。
  - 卡片圆角裁切不能靠 Border.ClipToBounds（不按圆角裁），改用 `VisualBrush` 白底圆角 Border 做 `OpacityMask`（固定尺寸 222x304 / 980x640）。
  - 选项两列用 `UniformGrid Columns=2`（WrapPanel 在 DataTemplate 里测宽受限，只会排一列）。
  - 收藏状态存 `%LOCALAPPDATA%\FlingTrainerX\state.json`，同步缓存 `library.json`。
- 坑：Bash heredoc 写 Python 脚本会把 `\s`、`\d`、`\u00b7` 转成 `/s`、`/d`，正则静默失效；改用 Write 工具落文件即可。
- 截图存 `docs/`，README 已重写（含架构、数据来源、构建方式）。

## 第二轮迭代（用户反馈）

- 弹框动画卡顿定位：`DropShadowEffect`/`BlurEffect` + `VisualBrush` 圆角遮罩 + 动画期间持续排版。
  改为：去掉遮罩改用 `Rectangle + ImageBrush` 自带圆角；遮罩层不透明不做整层淡入；先 `UpdateLayout()` 再动画；
  动画只做位移 + 透明度并临时挂 `BitmapCache`，结束即摘；选项列表与图片解码全部挪到动画之后。
  实测一次性布局 143ms → 48ms，动画帧间隔 16~19ms。
- 无限滚动：官网分页是 `/page/N/`，对应 WP 接口 `&page=N`，同时读 `X-WP-TotalPages` 响应头；
  滚动到距底 360px 触发，页数写进 `library.json` 的 `pages` 字段，重启后接着翻。
- 详情页补全：官网下载表格不在 REST 正文里，在详情页 HTML 的 `.download-attachments` 表里，需单独抓详情页；
  已把 24 款的 143 条下载记录（文件/地址/日期/大小/下载次数）预生成进 `trainers.json`。
- 详情改为 `Options` / `Download` 两个选项卡；Download 完整复刻官网四列表格；介绍图用正文首图（srcset 的 768 档）。
- 图片一律异步解码（`Task.Run` + `BitmapImage.Freeze`），网络图缓存到 `%LOCALAPPDATA%\FlingTrainerX\images`；
  新翻页的卡片封面后台下载后通过 `INotifyPropertyChanged` 就地替换（`TrainerItem.SetPoster`）。

  收藏夹视图按 created_at 倒序，卡片左上角有 ✕ 直接取消收藏，侧栏显示收藏数。
- 首页虚拟滚动：数据按 5 张一行切成 `Models/CardRow.cs`，交给 `ListBox + VirtualizingStackPanel`

## 第四轮迭代（直接下载 / 解析 / 中文化 / 高 DPI）

- 详情页下载改为**应用内直下**，不再跳浏览器：`Services/DownloadManager.cs` 单例，`MaxConcurrent=2`，
  其余排队；`HttpCompletionOption.ResponseHeadersRead` + 80KB 缓冲流式写盘，`Stopwatch` 算速度，
  UI 每 120ms 节流刷新；落点 `%USERPROFILE%\Downloads\FlingTrainerX`，重名 `UniquePath()` 加 (2)，
  失败删残文件。`Models/DownloadTask.cs` 是状态机（Queued/Running/Completed/Failed/Canceled）。
- 官网下载链路：`/downloads/<slug>/` → 302 `download-trainer.php` → 302 真实 `.exe`，
  `Transfer-Encoding: chunked` **无 Content-Length**。所以**不能**拿官网标注大小当分母
  （931 KB vs 实际 1.7 MB，会冲到 100% 卡住），只用真实 Content-Length；没有时用
  `ThinProgress` 的 Indeterminate 流光条 + 「已下载 X」。
  流光条动画必须**往返**（From=-60 To=330 AutoReverse），单向跑到 620 会在窄条上整段时间不可见。
- 侧栏导航改为 4 项：游戏库 / 收藏夹 / 下载队列 / 设置（删掉「修改器」）。队列页卡片显示
  进度条、速度、剩余时间，按钮 取消/重试/打开文件夹/移除，页头 打开下载目录 + 清理已完成。
- 详情页下载表格加「操作」列 + 行内进度条：`ViewModels/DownloadRowVm.cs` 把官网下载记录和
  下载任务合成一行，按钮在 下载/取消/重试/打开 之间切换。
- 解析全部换成 **AngleSharp 1.9**，项目内已无任何正则：`HtmlParser.ParseDocument` +
  `QuerySelector(All)`；解析前删 `script/style/noscript/svg`（官网选项后面塞了 jQuery
  `toolTips(...)`，是乱码元凶）；`<br>`→`\n` 用 `(IElement)element.Clone(true)` 后处理。
- 选项名全中文：`Assets/option-zh.tsv` 627 条精确对照（选项名 + 分组标题，覆盖率 100%），
  `Services/TrainerZh.cs` 查表 → 词根拼接兜底（Prefixes×Nouns）→ 原文；`Platform()` 译平台名，
  `Normalize()` 归一弯引号/不换行空格/大小写。
- 高 DPI：新建 `app.manifest` 声明 `dpiAware=true/pm` + `dpiAwareness=PerMonitorV2`；
  `MainWindow` 用 `MonitorFromWindow`+`GetMonitorInfo` 取物理像素，除以 `VisualTreeHelper.GetDpi`
  换算 DIP 定窗口大小，`OnDpiChanged` 重算；详情弹框 `FitTo(w,h)` 自适应（960×520 也能收进去）。
- 开发期自检（`#if DEBUG`）：`FlingTrainerX.exe --capture <dir>` 跑一遍主流程截图后退出，
  用于核对 UI；截图脚本命名 01-main … 11-small-window-detail。
- 文档：`docs/` 五张图（main/opt/dl/queue/fav，1440 宽），README.md 重写（新增
  「直接下载与下载队列」「中文界面」「AngleSharp」「PerMonitorV2」章节），README.en.md 从
